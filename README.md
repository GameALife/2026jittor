  输出：result.json
        key   = 测试节点编号（字符串）

  注意：测试集标签在数据里是 -1（已隐藏），只能靠模型预测。

  节点 2708（每篇论文一个节点）
  边   5429（引用关系）
  特征 1433 维（词袋）
  类别 7

【cora.pkl 字段】
  x            (2708, 1433)  节点特征
  y            (2708,)       标签；测试集为 -1
  edge_index   (2, E)        边列表
  train_mask / val_mask / test_mask
  num_classes / num_features

【怎么跑（本机 release/）】
  1. 安装 Jittor + JittorGeometric
  2. 确认 data/cora.pkl 存在
  3. 按 gcn.py 里 TODO 填完整

【提交】
  result.zip
    ├── gcn.py        # 模型 + 训练代码
    └── result.json   # 测试集预测
  示例：

【通过线】
  Accuracy ≥ 0.70

三、赛道一正式赛：基于图学习的动态推荐（时序链接预测）
================================================================================

【一句话】
  已知历史上的交互 (源节点 u, 目标节点 v, 时间 t)，
  在未来某个时刻，给定源节点 u 和 100 个候选目标，
  预测 u 与每个候选发生交互的概率，并按概率排序。

【为什么难】
  很多时序图数据里「重复边」很多，模型容易死记硬背历史连接，
  而不是学真正的时序规律。本赛题更看重对新连接的泛化。

【举例（社交）】
  时刻 0：A→B
  时刻 1：B→C
  预测：时刻 2，A 与候选 [B,C,D] 的交互概率，例如 (0.40, 0.50, 0.10)

--------------------------------------------------------------------------------
3.1 数据下载与本地位置
--------------------------------------------------------------------------------
  A 榜：https://cloud.tsinghua.edu.cn/f/6a9569def9044d49bb96/?dl=1
  → release3/

  A 榜难度适中；B 榜更大规模（节点百万、交互千万级），
  算法应能兼顾不同量级（AB 榜方法应基本一致）。

  数据含二部图与非二部图：
    二部图：src 与 dst 分属不同集合（如用户-物品）
    非二部图：src 与 dst 同一集合（如用户-用户）

--------------------------------------------------------------------------------
3.2 数据格式（务必看懂）
--------------------------------------------------------------------------------

【训练集 train.csv】每行一次历史交互
  列：src, dst, time
  含义：源节点 src 在时间 time 与目标节点 dst 发生交互

  示例：
    src,dst,time
    862247,1,0
    862248,53,3

  文字示意（与赛题图一致）：
    u1, i1, t1
    u2, i3, t1
    u1, i2, t2
    ...

【测试集 test.csv】每行一次待预测查询
  列：src, time, c1, c2, ..., c100
  含义：在时刻 time，源节点 src 面对 100 个候选目标 c1~c100
  你要输出：这 100 个候选各自的交互概率（与 c1~c100 顺序一一对应）

  示例：
    src,time,c1,c2,...,c100
    862300,150000,17,920,41,...,127

【A 榜数据集统计（含测试边，来自 release3/readme）】
  dataset1：非二部图；节点约 23,852；边约 751,899；重复率约 0.87
  dataset2：二部图；节点约 63,348（12,708 / 50,640）；边约 2,414,703

  本机目录：
    release3/dataset1/train.csv, test.csv
    release3/dataset2/train.csv, test.csv
  （部分环境也可能放在 release3/data/datasetX/ 下，以你实际解压为准）

--------------------------------------------------------------------------------
3.4 评测：MRR（平均倒数排名）
--------------------------------------------------------------------------------

  对每个测试查询：把 100 个候选按预测概率从高到低排序，
  看「真正会发生交互的那个目标」排在第几名，记为 rank_i。
  该查询得分 = 1 / rank_i
    排第 1 → 1.0
    排第 2 → 0.5
    排第 3 → 约 0.333
    ...

  一个场景（一个数据集）的 MRR：

    MRR = (1 / |Q|) * Σ_{i=1}^{|Q|} (1 / rank_i)

  其中 |Q| = 该场景测试查询数量。

【A 榜最终分】
  各场景 MRR 的均值之和（多个 dataset 的 MRR 加总 / 按官方规则汇总）。

【B 榜最终分】
  （各场景 MRR 之和）× 65%  +  答辩分 × 35%

  A 榜结束后按排名筛选进入 B 榜。

四、赛道二正式赛：基于深度学习的点云降噪
================================================================================

【一句话】
  输入含噪点云，预测每个点的位移，把点「推回」真实物体表面，输出干净点云。

【直观理解】
  左：干净真值 GT
  中：加噪输入 Noisy
  右：模型输出 Denoised（应尽量贴近表面）

【数学目标】
  输入含噪点：  { p_i + n_i }   （p_i 在真实表面，n_i 是噪声）
  模型预测位移：Δ_i
  降噪结果：    p̂_i = p_i + n_i + Δ_i
  希望 p̂_i 尽量贴近真实表面。

  评测用两个距离再映射成百分制：
    CD  （Chamfer Distance，预测点云 ↔ 干净点云）
    P2S （Point-to-Surface，预测点 → 原始网格表面）

4.3 Baseline（StraightPCF 思路，Jittor 实现）
--------------------------------------------------------------------------------

  结构概要：
    - 特征：动态图卷积（KNN 建局部图）提局部几何特征

  环境与命令（详见 release4/starter_code/README.md）：

    pip install -r requirements.txt

    # 推理

  本机也可：

    source ./setup_cuda_env.sh
    ./run_all.sh          # 训练 + 推理 + 打 result.zip

--------------------------------------------------------------------------------
4.4 评测指标（公式写成可读形式）
--------------------------------------------------------------------------------

【指标一：Chamfer Distance (CD)】
  预测点云 S_pred 与干净点云 S_gt 的双向最近点距离（平方）：

    CD(S_pred, S_gt)
      = (1/|S_pred|) * Σ_{x∈S_pred}  min_{y∈S_gt} ||x-y||²
      + (1/|S_gt|)   * Σ_{y∈S_gt}    min_{x∈S_pred} ||y-x||²

  计算前：把 S_gt 归一化到单位球（中心化 + 最大半径=1），
          S_pred 用同一变换，消除尺度差。

【指标二：Point-to-Surface (P2S)】
  预测点到原始干净网格表面 M 的最近距离平方均值：

    P2S(S_pred, M)
      = (1/|S_pred|) * Σ_{x∈S_pred}  min_{y∈M} ||x-y||²

  相对 CD，P2S 对「糊掉细节 / 整体漂离表面」更敏感。
  同样在单位球归一化空间下计算。

--------------------------------------------------------------------------------
4.5 百分制得分（以「含噪输入」为零分基线）
--------------------------------------------------------------------------------

  对每个测试样本 i：

    cd_score_i  = clamp( 100 * (1 - CD_pred(i)  / CD_noisy(i) ),  0, 100 )
    p2s_score_i = clamp( 100 * (1 - P2S_pred(i) / P2S_noisy(i)), 0, 100 )

  含义：
    - CD_pred / P2S_pred：你的降噪结果
    - CD_noisy / P2S_noisy：原始含噪输入（基线）
    - 若你和「不降噪」一样差 → 约 0 分
    - 若距离降到接近 0 → 接近 100 分
    - clamp 把分数截断在 [0, 100]

【A 榜最终分】（所有测试样本全局平均，不分类别；CD 与 P2S 各 50%）

    Score_final
      = 0.5 * (1/N) * Σ cd_score_i
      + 0.5 * (1/N) * Σ p2s_score_i

【B 榜】
  评测方式可能根据 A 榜结果再调整以拉开差距。
  最终：65% 评测分 + 35% 答辩分。
