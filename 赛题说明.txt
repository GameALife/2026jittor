赛道一：基于图学习的动态推荐任务
赛题介绍
近年来，随着推荐系统、社交网络、交易网络等图数据的不断丰富，时序图学习成为图机器学习领域的重要研究方向。与静态图不同，时序图中的节点关系会随时间不断演化，模型不仅需要理解图结构本身，还需要捕捉交互行为背后的时间规律与序列模式。

本赛题聚焦时序图中的未来链接预测任务。给定用户、物品、作者、网页等实体在历史上的交互序列，模型需要预测未来最有可能发生的新连接。具体来说，赛题会提供一系列时序交互三元组 (source, destination, time)，参赛者需要结合序列推荐或时序图学习方法进行建模，学习用户、物品或节点之间的时序关联模式，并在给定 time 和 source 的情况下，预测其未来可能交互的 destination。


例如在社交网络情境下，已知用户A,B,C,D的历史交互记录为：

时刻 0：用户A发起与B的交互(A,B,0)
时刻 1：用户B发起与C的交互(B,C,1)
在上述时序交互三元组中，source 和 destination 均对应于社交网络中的用户节点。模型需要预测用户节点A于时刻 2 的可能交互，给出与候选节点产生交互的概率，例如[B,C,D]：(0.40,0.50,0.10)，代表了预测的用户节点A于时刻 2 分别与用户节点B,C,D发起交互的概率。

本赛道的任务可建模为时序图节点重排序任务，我们为参赛者提供了基于JittorGeometric库实现的代码作为Baseline，使用方法详见仓库的README说明。

赛题意义与挑战
该任务广泛存在于商品推荐、好友推荐、论文引用预测、网页跳转预测等场景中，具有重要的研究价值与应用意义。近年来研究表明，现有不少时序图数据集存在重复边比例较高的问题，模型往往更容易依赖对历史连接的记忆，而不是学习更加真实且更具挑战性的序列动态规律。因此，如何提升模型对未来新连接的建模能力与泛化能力，仍然是时序图学习中的关键挑战。

赛道二：基于深度学习的点云降噪任务
赛题介绍
随着三维传感技术（如激光雷达 LiDAR、结构光扫描、深度相机等）的快速发展，点云数据已成为三维计算机视觉和图形学领域最重要的数据表示形式之一。然而，受限于传感器精度、环境干扰（如光照变化、反射噪声）和采样过程中的量化误差，实际获取的点云数据往往包含大量噪声，表现为点偏离真实物体表面，严重影响后续的三维重建、表面法向估计、形状分析、物体识别等下游任务的精度和可靠性。

点云降噪（Point Cloud Denoising）旨在从含噪点云中恢复出贴合真实物体表面的干净点云，是三维数据预处理中的核心环节。传统方法（如基于移动最小二乘法 MLS、双边滤波、基于法向的滤波等）通常依赖手工设计的几何先验，在面对复杂几何结构和不同噪声分布时泛化能力有限。近年来，基于深度学习的方法凭借其强大的数据驱动特征提取能力，在点云降噪任务上展现了显著优势。代表性工作包括 PointCleanNet、Score-Based Point Cloud Denoising、DMRDenoise 等，这些方法通过学习点云局部几何特征和噪声模式，能够更鲁棒地还原真实表面。

本赛题聚焦基于深度学习的点云降噪任务。给定从三维物体表面采样并受噪声污染的点云，参赛者需要设计并训练深度学习模型，预测每个点的位移向量，将含噪点"推回"到真实物体表面附近，输出降噪后的点云。

赛题背景与意义
学术意义
点云降噪是三维几何处理中最基础也最具挑战性的问题之一，与以下核心研究方向密切相关：

三维重建：高质量的三维重建（如 Poisson Surface Reconstruction）高度依赖输入点云的质量，噪声会直接导致重建表面出现伪影和几何失真。
表面法向估计：点云法向量是曲面微分几何的核心量，噪声会严重干扰法向估计的精度，进而影响渲染、网格化等流程。
自动驾驶与机器人感知：激光雷达点云是自动驾驶中环境感知的关键输入，噪声会影响障碍物检测和语义分割的可靠性。
文化遗产数字化：对古建筑、文物等进行三维扫描时，噪声处理直接影响数字化保存的精度和质量。
技术挑战
噪声分布多样性：实际噪声可能服从高斯分布、拉普拉斯分布或更复杂的非均匀分布，模型需要对多种噪声类型具备鲁棒性。
几何细节保持：降噪的同时需要尽可能保留尖锐边缘、棱角等细节结构，避免过度平滑。
可扩展性：实际场景中的点云规模从数千到数百万点不等，模型需要在不同数据量级上都能高效运行。
泛化能力：模型需要在训练集未覆盖的物体类别上也能取得良好的降噪效果。

Baseline 采用以下架构：

提交格式说明
A、B 榜分别提交降噪结果，所有文件打包为 result.zip。每个测试样本对应一个 .npy 文件（NumPy 二进制格式，float32），文件命名与测试集目录结构保持一致。

提交文件目录结构（与测试集目录结构一致）：

-- result.zip
  -- shapenet/
    -- <synset_id>/
      -- <model_id>/
        -- denoised.npy
      -- ...
    -- ...
.npy 文件格式：

每个 .npy 文件存储一个 shape 为 (N, 3) 的 float32 NumPy 数组，其中 N 为点数，3 列分别为 (x, y, z) 坐标。生成方式示例：

import numpy as np
# denoised_points: shape (N, 3), float32
np.save('denoised.npy', denoised_points.astype(np.float32))
每个文件的点数 N 必须与对应的含噪输入点数严格一致。

评测脚本
组委会提供评测脚本 evaluate.py，选手可在本地验证提交结果：

python evaluate.py \
    --pred_dir ./results \
    --gt_dir ./test_gt \
    --noisy_dir ./test_noisy \
    --mesh_dir ./dataset_clean \
    --workers 8 \
    --verbose
其中：

--mesh_dir：指定原始网格目录，用于计算 P2S 指标（需安装 point-cloud-utils）。若省略该参数，将仅计算 CD 得分。
--workers：并行进程数，默认自动使用全部 CPU 核心。
注意事项
选手需通过热身赛后才能参加此赛题。
比赛需要使用计图（Jittor）深度学习框架。
比赛不得使用除了提供数据集之外的其他数据，否则视为放弃参赛资格，自动退出比赛。
比赛中用于不同类别的神经网络模型、权重、训练参数等均可不同，不作特殊限制。
提交的降噪点云中每个文件的点数必须与输入含噪点云的点数严格一致，否则评测将报错。
所有团队（包括热身赛和正式赛题）需要按照开源指南进行代码开源，才能视为有效成绩，详见赛事介绍。
为了保证评测效率和公平，每队伍每天最多提交两次。
